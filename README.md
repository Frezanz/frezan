# frezanz

A lightweight personal website and futuristic HUD interface for exploring ideas, systems, and work in progress.

## Stack
- React + Vite
- Framer Motion
- Canvas 2D for the home reactor
- CSS glass / HUD interface
- Three.js for the dedicated, interactive Model Architecture explorer

## Exploration index

The **More** section groups six destinations into three areas:

- **Systems:** Model Architecture, Relational Framework, Cognitive Systems & Memory
- **Research:** Research & Hypotheses, Knowledge Archive
- **Workbench:** Projects & Experiments

The architecture explorer is an explanatory visualization of a proposed research design. Its graph is not live runtime telemetry and does not imply that the integrated system is already implemented. Pages should distinguish conceptual designs, working prototypes, and verified results.

The home interface avoids a continuously rendered 3D scene so it remains responsive on mobile devices.
